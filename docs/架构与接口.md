# 架构与接口

## 边界与运行路径

项目由宿主入口、窗口编排、纯数据处理、宿主适配及界面组件组成，不包含后端服务，也没有对外 HTTP 接口。

`src/index.ts` 导出 `openBomCheck(): Promise<void>` 与 `about(): void`，供清单菜单调用。启动函数从宿主视口计算窗口尺寸，打开包内 `/iframe/index.html`，窗口标识为 `bomcheck-main`。信息入口显示独立的中文名称、英文名称、版本、作者及网站。

`src/ui.ts` 持有当前文件、工作表、范围、比较结果、映射、计划和操作记录。配置改变使比较结果失效；写入与删除完成后同样失效。页面读取官方注入的 `eda` 对象，纯处理模块不依赖宿主页面 DOM。

## 数据结构与处理接口

以下接口属于项目内部模块，不是供其他扩展调用的已注册外部服务。完整类型以 `src/model.ts` 为准。

| 结构 | 内容与作用 |
| --- | --- |
| ParsedSheet | 按实际行列保存的稀疏单元格、原始单元格、候选表头、解析问题及冲突行 |
| BomData | 文件、工作表、位置区分的列、展开位号记录、问题和大小写规则 |
| Scope | 工程身份、原理图或 PCB 类型及需要处理的文档集合 |
| ComponentSnapshot | 文档与图元身份、位号、唯一标识、单元名、标准属性、其他属性及结构详情 |
| Comparison | 两侧索引、两类差异、匹配数和问题，不代表属性一致性检查 |
| Mapping | 一个目标字段、有序来源列和合并分隔符 |
| WritePlan | 按器件组织的字段变更、问题、覆盖数及无需修改数 |
| OperationRow | 操作结果与说明，填写结果附带前后值和来源 |

`loadWorkbook(bytes, filename, encoding)` 异步校验 ZIP 格式输入后解析工作簿。`readWorkbook` 提供同步解析，文本按明确编码严格解码。`sheetColumns(sheet, headerRow)` 生成位置唯一的列标识，`buildBom` 根据表头、位号列、分隔符和大小写选项生成独立记录。模块内部表头与列索引从零开始，界面行号从一开始。

`compare(bom, components)` 建立位号存在性索引。`isUnambiguousGroup` 判断同位号工程组能否作为单个器件或多单元器件处理。`planWrites(result, mappings, fields, clearEmpty)` 生成填写计划，不直接修改工程。重复来源文本不一致、无效来源和非法真假值记录为问题。

`exportTables(first, second)` 返回 Excel 字节数据。`componentRow`、`bomRow` 和 `previewRows` 负责统一显示数据转换。`operationLog(recovery, operation)` 返回 `metadata`、`recovery`、`operation` 三个顶层字段，不递归删除业务属性。

## 宿主适配

`EdaHost` 是业务层访问官方 `eda` 接口的集中入口。

| 方法 | 官方能力与实际行为 |
| --- | --- |
| scopes | 从当前工程树枚举 PCB 与原理图，展开板子下的对象，保留全部图页 |
| assertProject、activate | 核查工程身份，打开目标文档并核实当前文档 |
| readScope、readOne | 分别读取范围快照或重新读取单个器件，不跨文档复用旧图元对象 |
| write | 调用原理图或 PCB 器件 modify，保留其他属性字典，再读取实际值 |
| removeMany、remove | 调用器件 delete，并用剩余图元标识核验结果 |
| save | 遍历范围内文档调用对应文档 save，明确记录 false 返回导致的失败 |
| confirm | 将宿主确认对话框回调转换为异步结果 |
| saveFile | 将 Blob 与建议文件名传给 sys_FileSystem.saveFile |
| storeRecovery、recovery | 使用扩展用户配置的 recovery 项保存和读取操作前数据 |

宿主接口按能力检测决定是否使用工程与文档就绪方法。缺少文档就绪方法时，按图元标识集合连续稳定读取确认加载，超时不返回不完整的范围结果。原理图逐页读取明确只取当前页器件，再由范围遍历组成全部图页结果。

## 写入与删除顺序

写入顺序为重新生成预演、保存恢复计划、确认已有值覆盖、检查工程、重新读取器件身份及目标字段、按器件合并修改、重新读取核验、保存范围文档、展示日志并使差异失效。恢复数据保存早于确认，取消也会留下计划。

删除顺序为保存候选快照、检查清单与解析问题、筛选无歧义候选、整批确认、按文档分批重新核查身份、数组删除、读取剩余标识、处理未生效对象、保存文档、展示日志并使差异失效。批量核验失败不盲目重复整批删除。

局部失败通过结果行记录，其余目标继续执行。工程保存有单独结果，整个批次没有事务回滚。恢复快照不是完整工程文件，也没有恢复导入接口。

## 共享规则与资源管理

`src/rules.ts` 集中保存默认分隔符、大小写规则、结构字段排除、字段定义、可见内容判断、文本转换及操作批量参数。业务模块应复用这些规则，不在导出或界面中重新解释一遍。

文件选择器使用窗口标准文件控件，每次选择独立创建，完成或取消后移除控件及事件。表格在页面可见时创建，切换时保留滚动位置。窗口关闭释放表格、映射编辑器、分隔符编辑器、滚动区域、文件选择器和尺寸观察器。

构建与交付共享 `build/package-files.mjs` 的文件清单，身份信息共享 `extension-info.json`。增加包内资源时须同步真实资源引用与共享清单，核验不应依赖历史验收文档。
